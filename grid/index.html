체결 기록하기

매직스플릿에서 체결이 나면 여기서 입력하세요. 아래 표가 바로 바뀝니다.

매수: 해당 차수에 수량·체결가가 들어가고 실제 매입단가 = 체결가가 됩니다(매직스플릿 매수가도 체결가로).
매도: 해당 차수를 비우고, 실제 매매내역·손익 대조에 한 줄이 추가됩니다.

차수별 보유 현황

노란 칸은 직접 고칠 수 있습니다. 매도목표가는 매직스플릿이 쓰는 값(MS 매수가 × (1+마진))입니다.

그리드 차수표

실제 체결 내역 (키움 5531 계좌)

9/8 이후 매수는 주문 단위 체결가, 손익·수수료는 키움 실현손익 API(매수·매도 수수료 차감, 이동평균 단가). 2026-10-06 계좌 조회로 확인.

체결 직접 추가

9/14 이후 매도 손익 — 매직스플릿 표시 vs 실제

그리드 기준 실제손익 = (매도가 − 실제 매입단가) × 수량 − 수수료. 키움 실현손익은 이동평균 단가 기준이라 10/1 매도처럼 차수별로는 다를 수 있지만 총손익은 같습니다.
